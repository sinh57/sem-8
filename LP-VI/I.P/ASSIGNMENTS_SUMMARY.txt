ASSIGNMENT 1: IMAGE SUBSAMPLING AND RESAMPLING
===============================================================================

📁 Folder: Assignment_1_Subsampling_Ubuntu
📄 Main File: assignment_1.py
🖼️ Input Image: tiger_image.jpeg (276x183 pixels)

WHAT IT DOES:
✓ Loads tiger image
✓ Subsamples to: 512x512, 256x256, 128x128, 64x64, 32x32
✓ Resamples each back to 1024x1024
✓ Compares quality using MSE and PSNR metrics
✓ Uses bilinear interpolation (INTER_LINEAR)

OUTPUT:
1. Original Tiger Image (276x183)
2. Subsampled versions (512x512, 256x256, 128x128, 64x64, 32x32)
3. Resampled versions back to 1024x1024
4. Comparison view showing all resolutions
5. MSE/PSNR Analysis for quality assessment

TECHNIQUES:
- Subsampling: Reduces image size using interpolation
- Resampling: Enlarges image back to original dimensions
- Interpolation: INTER_LINEAR (bilinear)

ASSIGNMENT 3: IMAGE ENHANCEMENT
===============================================================================

📁 Folder: Assignment_3_Enhancement_Ubuntu
📄 Main File: assignment_3.py
🖼️ Input Image: nature.png

PART A: CONTRAST STRETCHING
WHAT IT DOES:
✓ Extracts RGB channels
✓ Applies linear stretching: new_val = ((old_val - min) / (max - min)) * 255
✓ Merges channels back
✓ Displays original vs stretched comparison

OUTPUT:
- Original Image
- Contrast Stretched Image
- Histogram comparison showing expanded range

TECHNIQUES:
- Channel separation: cv2.split()
- Linear transformation for each channel
- Channel merging: cv2.merge()

PART B: INTENSITY LEVEL SLICING
WHAT IT DOES:
✓ Converts image to grayscale
✓ Creates mask for intensity range [100, 200]
✓ Extracts pixels within range
✓ Shows multiple intensity levels (5 ranges)
✓ Binary and colored results

OUTPUT:
- Original Grayscale Image
- Intensity Mask
- Binary Sliced Result
- Color Sliced Result
- Histogram with slicing range highlighted
- Multiple intensity level visualization

TECHNIQUES:
- Range masking: cv2.inRange()
- Bitwise operations: cv2.bitwise_and()
- Multiple intensity level extraction

===============================================================================
QUALITY METRICS EXPLAINED
===============================================================================

MSE (Mean Squared Error):
- Lower is better (closer to 0)
- Measures average squared difference between original and resampled

PSNR (Peak Signal-to-Noise Ratio):
- Higher is better (typically 20-50 dB)
- Measures quality of image reconstruction
- Formula: PSNR = 10 * log10((255²) / MSE)
